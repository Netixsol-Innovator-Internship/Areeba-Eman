Skincare App

A modern skincare app designed to help users explore, manage, and personalize their skincare routines. The app is powered by Redux Toolkit (RTK) and RTK Query for smooth state management and efficient API data fetching.

Features

Browse skincare products with detailed information

Search and filter based on skin type, ingredients, or concerns

Save favorite products and routines

Seamless data fetching and caching with RTK Query

Fast and responsive user interface

🛠️ Tech Stack

React – for building the user interface

Redux Toolkit – for centralized state management

RTK Query – for efficient API communication and caching

Tailwind CSS – for modern, responsive styling

📂 Project Structure

The project is structured around clear separation of concerns:

App configuration (store and API setup)

Features (skincare data, routines, favorites)

Components (reusable UI elements)

Pages (user-facing views like Home, Product Details, Routines)

🔧 Installation & Setup

Clone the repository

Install dependencies

Run the development server

📊 Data Management with RTK Query

RTK Query is used to:

Fetch skincare product data from an API

Cache results to minimize network requests

Provide built-in loading and error states

Keep the UI fast and responsive
