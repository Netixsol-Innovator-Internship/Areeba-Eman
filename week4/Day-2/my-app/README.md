Job Board – Next.js + Zustand

A simple Job Board application built with Next.js. It demonstrates:

-File-based routing (including dynamic routes for job details)
-API Routes for serving mock job data
-Global state management with Zustand

Features

-Browse available jobs (mock data from API routes).
-Filter jobs by category or location using global state.
-Filters are saved in localStorage so they remain after refresh.
-Click on a job to see a details page at /jobs/[id].
-Optimized for performance with Next.js.

Tech Stack
Next.js
 – React framework
Zustand
 – Global state management
Vercel
 – Hosting & deployment
