# Web3 DApp Suite 🚀

A complete decentralized platform that brings together a multi-token DEX, NFT marketplace 
with royalties, token faucet, and portfolio dashboard — all in one place.

Live Demo: areeba-web3-dapp.vercel.app

Network: Ethereum Sepolia Testnet

# Overview

This DApp lets users claim free tokens, swap between multiple assets, mint and trade NFTs,
and manage their entire crypto portfolio — everything built around a single ecosystem.

# Smart Contracts

All contracts are deployed and verified on Sepolia Testnet.

PlatformToken (PLT) – Core ERC20 token used for trading, minting, and marketplace fees.
TokenFaucet – Lets users claim free PLT tokens once every 24 hours.
MultiTokenDEX – Supports multi-token swaps and liquidity pools with a 0.3% trading fee.
DaisyNFT Collection – 100 limited NFTs with IPFS metadata and royalty support (ERC2981).
NFT Marketplace – Allows minting, buying, and selling NFTs with automatic royalties and
multi-token payments.

# Tech Stack

Built using Next.js 14, TypeScript, Tailwind CSS, Wagmi, Viem, and RainbowKit for a smooth 
Web3 experience.
Includes real-time token updates, wallet integrations, and IPFS-powered NFT storage.


# DApp Flow

1- Connect wallet (MetaMask or others)
2- Claim faucet tokens
3- Swap or add liquidity on the DEX
4- Mint or trade NFTs
5- Track balances and approvals in the portfolio dashboard

# Example User Journey

–> Claim faucet tokens → Swap → Add liquidity → Mint NFT
–> List NFT for sale → Get royalty on sale → Check updated portfolio
